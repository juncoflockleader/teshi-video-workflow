# 人物 / 动物谱

原则：**名字是容器，属性是模板。** 同一个名字在不同篇里互相矛盾是特点不是 bug。人物只有五个属性：姓名、年龄、职级/星座、籍贯、一句状态。

> 「老马，35岁，副科级干部，喜欢猫家里不让养」
> 「李大根，43岁，理科星座大师，东北人，今天买鱼被安徽人骗了。」
> 「王大锤，45岁，在同学聚会上一言不发。热爱生活。」
> 「老刘，45岁副主任科员，感觉自己今后的仕途布满荆棘」

## 动物层语法速查

- 量词一律「一个」：一个狗、一个猫、一个驴、一个熊、一个猴、一个鱼。
- 爪子叫「前手 / 后腿 / 左前手 / 右前手 / 双前手」，复数「前手们 / 后腿们 / 上肢们」。人也可以「右后腿挠左后腿内侧」。
- 动物有档案：祖籍、编制、工龄、借调、低保、进修、上过春晚。
- 动物小动作另起短句：「舔了一下左前手。」「舔嘴。」「挠腿。」「bia唧了一下嘴。」「双前手叉腰。」「捧心。」
- 动物比人体面，人比动物呆：动物讲 upgrade / infinity / indeed，人只会「奥」「嗯」「我没吭声」。
- 定语用畜牧/新闻腔：大型、巨型、成年、大棚、野生、青壮年、年迈的、河间三花、渤海、泌阳。
