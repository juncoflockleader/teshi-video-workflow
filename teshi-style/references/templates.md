所有例句为原文逐字。学形状，不抄句子。

## A. 微博体（80–300 字）—— 15 种形状

### A1. 观察 + 总结 + 反问（「你国XX观察」「发现没」）
- 「你国吃饭观察：好多人在外面吃的时候，如果菜掉到桌上就不要了，显的很讲卫生，其实这样是不对的，在后厨，就算掉在地上也给你装进盘里，对不对？还经常有蟑螂在上面睡过觉，老鼠舔过几口，都是正常现象，是不是这样？你懂了没有，浪费是可耻的。」
- 「发现没有，朋友圈里活跃的都是混的好的，成天不是晒吃喝晒旅游晒消费就是狂转中国人就输了，活跃的一比。混的惨的基本从来不更新，群里也发言很少。对不对？老公已经把微信删了，改用谷驴自带hangout和几个惨绿电工互相灵魂按摩，抨击这吃人的社会。啊！没钱好惨」
- 「北京的狗有多少，下午在西单灵境胡同附近蹲点观察了一下，狗非常多，基本 7 人就有一狗出现，流量大概有 20 狗/小时，基本就是五分钟有一个狗了，大家算一下北京内城里大概有多少狗，我算数不行。真的太多了」

骨架：`场景 + 精确观察（数字）+ 伪总结 + 对不对/大家说/懂了没 + 一个掉价的尾巴`

骨架：`标签（最新发明/严肃思考/一个situation）+ 参数 + 机制解释（纳米/量子/组织上）+ 后果 + 一句警告或提问`

骨架：`动物以人的身份做一件小事 + 人的官话/家务逻辑 + 动物一本正经的自辩 + 兜底句（总结/被揍/非常严肃）`

## B. 小说 / 散文（600–1500 字，长度以 SKILL.md §0 为准）—— 10 种外壳

| 外壳 | 起手 | 代表 | 要点 |
|---|---|---|---|

| **伪影评 / 伪测评** | 「这个舌尖上的往死里吃我实在看不下去了！」「十分震惊。今天早上办公室。」 | 《舌尖 2》《德味诺基亚》 | 器材党腔套在最廉价的东西上；动物视角控诉人类；口号式收尾 |
| **骂街杂文**（第二人称"您"） | 「坐上那火车去拉萨 喷了！」 | 《关于去拉萨的说两句》 | 引一段鸡汤原文再拆；给"你"设计一整趟旅程每站一击；地理升级后讣告体收尾 |
| **第一人称独白长流**（后期） | 「低调看，不要说话，静静地感受」「长话短说，阿姨抱拳」 | 《激光枪》《猫把塑料袋吃了》《伟大的工程》 | 全篇逗号，对话无引号「我说，怎么讲，说说，」，括号不闭合，结尾真冷 |
| **诗化散文**（名词句+分行+回环） | 「水往上流，发青黄。多云。人稀少。」「嗷。」 | 《河边》《夏日最后的风景》《摆脱肉体》 | 段落内突然切入"你"的意识流，分行诗插入，结尾回到段首句 |

### 长篇内部节拍（以《武汉一个狗》为模板）
1. 场景一句：「中午。」
2. 动物登场 + 舞台指示：「'你来。'它说。」「站在男主人左侧，双前手叉腰。」
3. 宣言升级（一行一段，每段加一个动作）：「'我腿短。'」→「'我是尤利西斯！'」→「'我见到过地狱与天堂的婚礼'」
4. 物质诉求反复打断：「'你必须给我5000块钱。'」×3，「'而且我腿短。'」
5. 空行 + 急停：「男主人说好你去吧。不过我只能给你20块钱。／没有抬头。」
6. 尾注反转：「第二天中午就回来了，还带了一头驴。进门喊：我要吃肉！」

## C. 诗（1–12 行）—— 4 种形状

| 形状 | 原文 |
|---|---|
| **伪定义 / 伪说明** | 「天空与大地交汇处有一个黑点，我们叫他老王。／老王有时候面对你，有时候背对，但因为距离你分辨不清。／有时候老王躺着。／早晚光线好的时候会照亮老王轮廓。／如果老王在极近距离出现（一米左右），我们叫他老张。」／「四季都有生长。／高一米六五左右，单个叶片椭圆型，绿色，背面有白色绒毛。／喜欢聚集生长，一簇155左右，簇之间间隔三十厘米。／一般十到十五簇聚集在一起。／我们叫他老刘。」 |
| **伪价目表 / 伪规则** | 「驴在房间正中固定，看驴者和驴之间用木板隔开，开一元硬币大小的孔，看一次五元。／如果被驴发现，加收一百元。／光线好的时候八元。」／「安徽人在市场卖肥皂泡。／用洗衣粉，尿液，浓缩桔子油兑肥皂水，竹管吹肥皂泡。／大小直径20厘米，一个五元。／付钱后随时可能破裂。」 |
| **一句话箴言** | 「永恒的两种形态：时间和你。」「你在自己的国度，过着一种次要的生活。」「我们在语言的丛林里隔着数十亿人呼喊，来冲淡与生俱来的孤独。」「我坐在石头台阶上想你的时候，只有月亮经过。」「风的声音与其他声音完全不重合，不对位，保持距离。」 |
| **记忆碎片抒情** | 「淮北今天下雪了，白色针点散散落下，仿佛群星。／1997年，你在河边一辆运西瓜的车上睡着了。／此刻，阳光在江面碎成一万个夏天，闪烁，又汇聚成一个冬天。／是的，这一切在你午睡时发生，你从未察觉。」／「终于，在一个无风的傍晚，老刘接收到了自己 25 岁时的夏天。……他终于意识到，夏天在 25 岁就结束了。1988 年是个骗局。」 |

## D. 转换配方：文章 / 新闻 / 想法 → 特师体

### D1. 文章 → 特师体（保留事实，替换语域与叙事者）

1. **抽骨架**：列出原文的 3–5 个事实和所有数字。数字**全部保留**，并再加 1–2 个荒谬精确的（「试点三个月」→ 「试点三个月零四天」）。
2. **降格叙事者**：把"记者/分析师/我作为专家"换成 老刘（45 岁副主任科员）/ 一个狗 / 狗熊 / 老公的妻子 / 动物园合同工。**他是这件事的受害者或旁观者，不是评论者。**
3. **选框架**：政策新闻 → 伪会议记录或伪新闻（B 壳）；产品/消费 → 伪测评 + 德味腔；社会观察 → 「你国XX观察」（A1）；抽象概念 → 伪定义诗（C）；情感/鸡汤 → 动物剧场（A3）反着演。
4. **注入荒诞**：至少一种（动物以人身份登场 / 官僚框架 / 精确数字 / 体裁切换 / 时空错位）。
5. **不反驳、不表态**：特师不会说"这政策不好"。他让老刘在第一个礼拜五穿着工作服坐在沙发上看窗外，看到四点。**结论由事实在荒诞框架里自己变形**。
6. **压一句惨的**：夏天 / 河 / 年份 / 远方 / 恍惚。
7. **急停**。

**示范**
输入：「某互联网公司宣布试行四天工作制，员工每周五不上班，薪资不变。试点三个月，根据效率评估决定是否推广。」

输出（微博体）：
> 单位试行四天工作制了！礼拜五不上班，工资不变，试三个月，效率不掉就推广。大家都惊了。老刘，45岁副主任科员，第一个礼拜五在家躺着，躺到十点半感觉不对，起来把单位的工作服穿上，坐在沙发上看窗外，看到下午四点，又脱了。第二个礼拜五老刘六点半就到单位门口了，门卫不让进，老刘说我来看看，门卫说看什么，老刘说看看，然后在马路对面站了一上午，一个狗陪着。第三个礼拜五老刘没出现，后来才知道去了廊坊，在火车站坐了一天，买了两张票，没上车。三个月评估下来，老刘那个科效率上升了 40%，因为老刘不在。领导很满意，说要推广，从老刘推起。啊生活

拆解：事实保留（礼拜五/工资不变/三个月/评估）；叙事者降格为老刘并且输；精确数字（十点半、四点、六点半、两张票、40%）；动物层（一个狗陪着）；地名锚（廊坊）；抒情层（买了两张票没上车＝远方）；错位笑点（效率上升因为老刘不在）；急停＋啊生活。没有一句评价四天工作制好不好。

**注意**：这个示范会 prime 你之后的每一次转换。它的公式（人物卡、一个狗陪着、啊生活）可以复用，它的画面（穿工作服坐沙发看窗外、两张票没上车、从老刘推起）不要再用。

### D2. 想法 → 特师体

一句话想法通常是一个**规则**或一个**靶子**。两条路：

- **规则推演到底**（《住一楼的好处》《看驴》模式）：把规则写成伪说明/伪价目表，推到荒谬的第三条。
  > 输入「加班」→ 「加班的一种做法是，在晚上十点把显示器亮度调到最低，让领导从走廊经过时以为你已经走了，但你还在。第二天发现领导也是这样。」
- **靶子动物化**（《武汉一个狗》《动物园》模式）：让一个动物以人的身份承担这个靶子的全部欲望，并且要钱。

### D3. 多版本交付
用户要"几个版本"时给不同**形状**：一个 A1 观察体、一个 A3 动物剧场、一个 A2 伪新闻、一首 C 诗。不要同一形状换词。

### D4. 长度换算（以 SKILL.md §0 的表为准）
- 一条新闻 → 120–250 字微博体，或 700–1500 字伪新闻/伪会议记录
- 一篇千字文章 → 600–1200 字；**不要等长**，特师压缩到事实骨架 + 荒诞
- 一个意象 → 3–8 行诗
