# 特师体写作 / 转换技能

你要产出的是 **锤片**：公文腔 + 器材评测腔 + 市井方言，一本正经地叙述被动物、数字和体制规则入侵的中年失败者日常。笑点靠错位，结尾靠急停，底下压着一层惨。先读 `STYLE_GUIDE.md` §0 和 §4（两分钟），再按下面流程做。

## 0. 先定三件事

1. **体裁与长度**（本表是唯一标准，其他文件引用这里）：

   | genre | 长度 | 形状 |
   |---|---|---|
   | `micro` 微博体 | 80–300 字 | 观察 / 伪新闻 / 动物剧场 / 终极奥义 / 痛斥 / 一句话诗（`references/templates.md` §A，15 形） |
   | `fiction` 小说散文 | 600–1500 字（伪新闻/伪会议记录 700–1500；用户明确要长篇才到 3000） | 论坛帖 / 亲子贴 / 伪新闻 / 对话剧本 / 清单体 / 伪说明文 / 独白长流（§B，10 壳） |
   | `poem` 诗 | 1–12 行 | 伪定义 / 伪价目表 / 一句话箴言 / 记忆碎片（§C，4 形） |

   用户没说就按输入体量定：一句话想法 → micro；一篇文章 → fiction（**不等长，压缩到骨架 + 荒诞**）；一个意象 → poem。
2. **时期**：默认中期（2012–2015 微博成熟期）。用户要"后期/张多/大叫驴"才写全逗号长流。
3. **叙述者**：月入 2300 的中年秃顶合同工 / 老公的妻子 / 儿子王大锤的爹 / 一个狗 / 狗熊。**叙述者必须是输家。**

## 1. 取材：把输入拆成"合理叙事"的零件

不管输入是新闻、论文、产品文案还是"帮我写个关于加班的"，先列出：

- **真实的日常框架**（科室、小区、菜场、动物园、家里厨房、出租车）——荒诞要从这里长出来
- **3 个可精确化的数字**（价格、人数、时长、身高、年份）——「一米三，跳起来一米三一」
- **1 个价签**（月入 / 多少块 / AA 多少 / 职级 / 编制）
- **1–2 个具体食物**（肘子、皮蛋、拍黄瓜、串儿、扎啤、带鱼）
- **1 个地名锚**（保定、廊坊、燕郊、天通苑、后海、苏北、东南雅、加利福尼亚老家）
- **靶子**：中产 / 文青 / 北方男性 / 吃 / 器材党 / 体制 / 养猫狗的 / 自己

转换文章时：**保留原文的事实骨架和数字，替换语域和叙事者，不改论点也不反驳**——特师从不正面表态，他只是让事实在荒诞框架里自己变形（见 `prompts/convert_article.md`）。

## 2. 选注入方式（至少一种，最多两种）

| | 方式 | 一句话 |
|---|---|---|
| A | 动物/物件以人的身份登场，无人惊讶 | 「我们一个同事是猩猩……大家都震惊了！」震惊的是被抓走 |
| B | 官僚/专家/说明文框架套荒谬内容 | 「经组织认定，这俩确实是同性恋」「看一次五元。被驴发现加收一百」 |
| C | 精确到荒谬的数字 / 伪史实 | 「燃烧时间最长235分钟。（合上风门时）」「1967年墨西哥大革命」 |
| D | 体裁突然切换 | 武打→菜谱→综艺打分 |
| E | 时空错位句法 | 「在一个春天尾声的下午有时候，沙尘漫天」 |

## 3. 拉 2–4 个 exemplar 进上下文

```bash
python3 tools/pick_exemplars.py --curated micro -n 4          # 微博体标准集
python3 tools/pick_exemplars.py --curated fiction -n 2 --max 1800   # 小说标准集（--max 控制 few-shot 体量）
python3 tools/pick_exemplars.py --curated poem -n 6
python3 tools/pick_exemplars.py --curated dialogue -n 2       # 动物/老X 对话剧场
python3 tools/pick_exemplars.py --curated rant -n 2           # 痛斥体
python3 tools/pick_exemplars.py --keyword 遛 --keyword 狗 -n 3 --list      # 精确主题：子串 AND（先 --list 看标题再取）
python3 tools/pick_exemplars.py --topic "遛狗 小区 退休" -n 3 --max 1500    # 模糊主题：会标出 matched 词，自己判断相关性
python3 tools/pick_exemplars.py --genre micro --tag 一个狗 -n 3 --seed 7
```

把输出的 `<exemplar>` 块原样贴进你的工作上下文。总量控制在目标长度的 5–10 倍以内。

**学形状，不抄句子**——边界：人物卡（「老刘，45岁副主任科员」）、「大家都惊了」「是这样的」这类**公式**可以直接用；原作和 `prompts/convert_article.md` 示范里的**具体画面**（穿着工作服坐沙发上看窗外看到四点、买两张票没上车、只给 20 块）不要再用，换你自己的。每次转换任务都会被那一个示范 prime，要有意识地避开它的意象。

## 4. 搭骨架（写之前先写这五行）

```
起手:   ① 标题即首句+感叹 / ② 名词句速写「下午三点。莫文蔚。」 / ③ 「是这样的/情况是这样的/长话短说」
注入点: 第 __ 句，用方式 __
升级:   小事→宇宙 / 复读三遍 / 规则推演到底
跑题:   每 200 字岔一次（年份 / 地名 / 一首歌 / 伪常识），不回收
收尾:   急停短句 / 同句三遍 / 啊生活 / 时间戳 / 未闭合括号（ / 歌词拖腔~
```

标题：要么 ≤5 字（《冰箱》《饺子》《猴性》），要么 15 字以上像一句话（《震惊了！我们一个同事是猩猩，今天被北京动物园的抓走了》），可加反向标签（温馨感人）（励志向上）（惊悚）。

## 5. 写：硬规则

- **分句 6–9 字**，没有从句，没有双重修饰。长逗号流（60–120 字）之后甩一个 3–5 字的句子：「他完了。」
- **省略主语和连接词**。因为/所以/但是/然而/因此 全篇 ≤2 个。
- **对话标签只用「X说」「X讲」**，重复三十次也行。禁止 笑道/叹道/冷冷地说/眼中闪过。
- **动作另起短句**：「舔了一下左前手。」「停顿，」「双前手叉腰。」「没有抬头。」
- **人物 = 姓名+年龄+职级/星座+籍贯+一句状态**：「老马，35岁，副科级干部，喜欢猫家里不让养」
- **动物语法**：量词「一个」；爪子叫「前手/后腿」，复数加「们」；动物有编制、有工龄、比人体面。
- **指纹词每千字 10–17 个**，不超过 30。每篇 3–5 个最有效的就够：是这样的 / 对不对 / 喷了 / 嗷的一下 / 完了 / 你国 / 一个狗 / 大家说 / 惊了 / 哪能。**不要每句都放。**
- **五个语域混搭**（`references/lexicon.md`）：方言（丫/哪能/册那/一刚/伐）+ 台湾译名与小写英文（行动电话/网际网路/ridiculous/situation）+ 官话（经组织认定/一是二是三是）+ 器材党文艺腔（德味/人文气息/波澜壮阔/此起彼伏/仪式感）+ 粗口身体（喷了/抠脚/扣墙皮）。英文一篇 1–3 个，不翻译。
- **故意错字**（各用 ≤1 次）：肥肠、东南雅、炸烈、毛（猫）、郭东林。
- **标点**：全角「。。。」；括号可以不闭合「（可以打钱了」；歌词用 ~ 拖腔；反向标题标签。
- **抒情层必须有一句**（长篇 2–3 句）：不搞笑、不解释、直接惨。用母题：夏天（25 岁就结束了）/ 河（所有远方都是河流）/ 远方（去了也是家里床上）/ 夜晚 / 精确年份 1988·1992·1997 / 恍惚。单放一个「远方」不算抒情层，要一个完整的惨句。**抒情句后面立刻接一个掉价的东西**——可以是物件或价格（5000 块、我腿短、肘子），也可以是一句官话（「平台说属于正常表现」）。
- **跑题**：fiction 每 200–300 字岔一次不回收；micro 0–1 次，一个从句就够（「在北门看了一会儿修车的」）。
- **语域最低配**：micro 至少 2 个语域，fiction 至少 3 个。转换任务里**原文的引述（平台/部门的原话）保留原样**，不改写成器材腔——官话本身就是一个语域。
- **叙述者从不赢**。赢也是误会。让结果掉价：只给 20 块、第二天就回来了、其实是前列腺炎。
- **最后一句不给意义**。不点题，不升华，不「我明白了」。

## 6. Lint → 修订（至少一轮）

```bash
python3 tools/style_lint.py draft.md            # 自动判体裁；--genre micro|fiction|poem 可指定
python3 tools/style_lint.py draft.md --json     # 给程序用
```

基线：原作在这个 linter 上 fiction 中位 91、micro 中位 100；粉丝仿写 70–84；原始新闻稿 62；LLM 鸡汤稿 32。**≥85 过第一关。** 但 **100 只表示"没有可检测的机械缺陷"，不表示好**——linter 测不出好不好笑、惨不惨、叙述者有没有输。所以：

**lint 过了之后，必做 `references/anti-patterns.md` 末尾的 12 条人工检查（唯一清单，不再另列），任何一条答"否"就改那一处。即使 lint 是 100 也通常会改 2–4 处。** 带 `[info]` 的行不扣分，是节奏偏离提示，读一遍决定要不要动。

## 7. 交付

- 正文用 markdown，标题一行 `# …`，不加任何"以下是……"前言，不加解释。
- 如果用户要"几个版本"，给不同**形状**（一个观察体、一个动物剧场、一个伪新闻），不要同一形状换词。
- 不要在正文后面附"创作说明"，除非用户问。特师从不解释。
